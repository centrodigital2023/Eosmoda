# Eosmoda

Eos Moda - Tu tienda de moda online. Este repositorio contiene el sitio web completo de Eos Moda, extraído de la aplicación eos-moda1.

## Contenido

- `index.html` - Página principal del sitio web
- `styles.css` - Estilos CSS para el diseño responsive
- `script.js` - JavaScript para interactividad
- `.github/workflows/deploy.yml` - Configuración de despliegue automático a GitHub Pages

## Características

- Diseño responsive y moderno
- Navegación suave entre secciones
- Catálogo de productos con 4 colecciones
- Formulario de contacto funcional
- Animaciones al hacer scroll

## Despliegue

El sitio se despliega automáticamente a GitHub Pages mediante GitHub Actions cuando se hace push a la rama `main`.
