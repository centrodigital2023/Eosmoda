# Eos Moda

Tienda de moda online - Sitio web oficial

## 🌐 Sitio Web

Visita nuestra tienda en línea: [https://eos-moda1--centrodigital2023.github.app](https://eos-moda1--centrodigital2023.github.app)

## 📝 Descripción

Eos Moda es una tienda de moda en línea que ofrece las últimas tendencias en ropa y accesorios. Nuestro sitio web presenta:

- Catálogo de productos por temporada
- Información sobre la empresa
- Formulario de contacto
- Diseño responsive para todos los dispositivos

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- GitHub Pages para deployment

## 💻 Desarrollo Local

Para ejecutar el sitio localmente:

1. Clona el repositorio
```bash
git clone https://github.com/centrodigital2023/Eosmoda.git
cd Eosmoda
```

2. Abre `index.html` en tu navegador favorito

## 📦 Estructura del Proyecto

```
Eosmoda/
├── index.html      # Página principal
├── styles.css      # Estilos del sitio
├── script.js       # Funcionalidad JavaScript
└── README.md       # Este archivo
```

## 🔄 Deployment

El sitio se despliega automáticamente a GitHub Pages cuando se hacen cambios en las ramas principales usando GitHub Actions.
