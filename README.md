# Eos Moda

Tienda de moda online - Fashion e-commerce website

## Descripción

Eos Moda es una tienda de moda online que ofrece las últimas tendencias en ropa para todas las temporadas del año.

## Características

- Diseño responsive y moderno
- Navegación suave entre secciones
- Catálogo de productos por temporada
- Formulario de contacto interactivo
- Animaciones y efectos visuales atractivos

## Despliegue

El sitio web está desplegado automáticamente en GitHub Pages mediante GitHub Actions.

URL del sitio: https://centrodigital2023.github.io/Eosmoda/

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- GitHub Pages
- GitHub Actions
